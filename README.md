# Melog - Beautiful Project Management Board

Experience the power of organization and task management with **Melog**, a beautiful Kanban Board developed using React, TypeScript, Tailwind CSS, and DnD-kit. Stay on top of your tasks and projects seamlessly with a Jira-like interface.

## ⚙️ Technology Stack:

- React with Vite  
- TypeScript  
- Tailwind CSS
- DnD-kit  

## ✨ Features:
- Beautiful Jira-like design with 4 fixed columns (TO DISCUSS, READY FOR DEV, REVIEW, IN DEVELOPMENT)
- Add, Edit & Delete Tasks  
- Drag tasks within their own column  
- Drag tasks across different columns  
- Custom beautiful scrollbars
- Responsive design with modern UI/UX
- Light theme with gradient backgrounds

## 🚀 How to run locally:
- Make sure you have Node.js and npm installed.
- Clone the repository: `git clone [your-repo-url]`
- Navigate to project directory: `cd melog`
- Install dependencies: `npm install`
- Start the development server: `npm run dev`
- Open your browser and visit: `http://localhost:5173`
